# docs — 五件套文档体系索引

| 阶段 | 目录 | 回答的问题 |
|---|---|---|
| SOW | `01-sow/` | 边界:做什么 / 不做什么 / 为谁做 |
| PRD | `02-prd/` | 需求:功能点、优先级、每条的验收 |
| ARD | `03-ard/` | 架构:模块、数据流、关键技术决策 |
| 测试报告 | `04-test/` | 质量:用例、覆盖率、缺陷与回归 |
| 交付 | `05-delivery/` | 交付:验收记录 + 用户手册 |

- 命名:`NN-类型-主题-vX.Y.md`(如 `03-ard-auth-v1.2.md`),R3 机检
- 新建:从 `templates/` 复制对应模板,必带 frontmatter(title / version / created / status),禁止空文件
- 旧版移入 `archive/` 并加 `ARCHIVED-日期-` 前缀,禁物理删除;`/docs/` 最新版本是单一事实源
- 上一阶段未确认不进入下一阶段;代码与文档同期演进(R6)
